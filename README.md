# 📱 MailCode Live OTP Monitor & Auto-Copy App

**code.yamin.bd** API-এর সাথে সংযুক্ত রিয়েল-টাইম Hotmail ও Outlook ওটিপি মনিটরিং এবং ইনস্ট্যান্ট নোটিফিকেশন অ্যাপ।

---

## 🌟 প্রধান ফিচারসমূহ (Key Features)

1. **রিয়েল-টাইম লাইভ মনিটরিং (Real-Time Live Monitor)**:
   - একসাথে ১০টি বা ইচ্ছামতো Hotmail / Outlook একাউন্ট ব্যাকগ্রাউন্ডে চেক করতে পারে।
   - প্রতি ৩/৫/১০ সেকেন্ড পর পর নতুন OTP চেক করে।
   - একই পুরনো কোড বারবার নোটিফাই করে না, শুধুমাত্র নতুন OTP আসলেই এলার্ট দেয়।

2. **স্মার্টফোন এসএমএস নোটিফিকেশন ব্যানার (Heads-Up Banner)**:
   - ওটিপি আসার সাথে সাথে ফোনের স্ক্রিনের ঠিক উপর থেকে এসএমএসের মতো সুন্দর ব্যানার ভেসে ওঠে।
   - সার্ভিসের নাম (Google, WhatsApp, Facebook, ইত্যাদি), ইমেইল এবং বড় করে জ্বলজ্বলে OTP কোড দেখায়।

3. **অটো-কপি (Instant Auto-Copy to Clipboard)**:
   - কোড আসার সাথে সাথে অটোমেটিক্যালি ক্লিপবোর্ডে কপি হয়ে যায় (`Copied to Clipboard!`)।
   - আপনাকে ম্যানুয়ালি সিলেক্ট বা কপি করতে হবে না।

4. **সাউন্ড ও ভাইব্রেশন এলার্ট (Chime & Vibration)**:
   - একদম ফোনের এসএমএস টোনের মতো মিষ্টি ডুয়াল-টোন রিংটোন বাজে (Zero-dependency Web Audio Synthesizer)।
   - মোবাইলে ভাইব্রেশন দেয়।

5. **স্ক্রিন ওয়েক লক (Screen Wake Lock)**:
   - ফোনের স্ক্রিন অফ হওয়া বন্ধ রাখে যাতে ব্যাকগ্রাউন্ড মনিটরিং নিরবচ্ছিন্নভাবে চলতে পারে।

6. **ফোনে ফুল অ্যাপ হিসেবে ইন্সটল (PWA - Add to Home Screen)**:
   - ফোনের ব্রাউজার (Chrome) দিয়ে ওপেন করে এক ক্লিকে **"Install App"** বা **"Add to Home Screen"** করলেই সাধারণ অ্যান্ড্রয়েড অ্যাপের মতো কাজ করবে।

7. **টেস্ট সিমুলেশন (Test Simulation)**:
   - আসল ওটিপি আসার আগেই **"Test Simulation"** বাটনে চাপ দিয়ে সাউন্ড, ভাইব্রেশন, ব্যানার এবং অটো-কপি টেস্ট করে দেখতে পারেন।

## 🚀 কীভাবে চালাবেন (How to Run)

### ১. সার্ভার চালু করতে:
টার্মিনালে লিখুন:
```bash
npm start
```

### ২. কম্পিউটার থেকে দেখতে:
ব্রাউজারে যান:
```
http://localhost:3000
```

### ৩. মোবাইল ফোন থেকে অ্যাপ ব্যবহার করতে:
কম্পিউটার এবং আপনার মোবাইল ফোনটি একই ওয়াইফাই (Wi-Fi) বা হটস্পটে কানেক্ট করুন, এরপর:
- ফোনের ক্রোম (Chrome) ব্রাউজারে লিংকটি লিখুন:
  ```
  http://192.168.0.101:3000
  ```
- অথবা কম্পিউটারের স্ক্রিনে থাকা **"Phone Connect"** বাটনে চাপ দিলে একটি কিউআর কোড (QR Code) আসবে, ফোন দিয়ে স্ক্যান করলেই খুলে যাবে!

### ৪. ফোনে অ্যাপ হিসেবে ইনস্টল করার নিয়ম:
1. ফোনে লিংকটি ওপেন করুন।
2. Chrome ব্রাউজারের উপরে **"Install App"** অপশন আসবে, অথবা ৩ ডট মেনু (⋮) তে গিয়ে **"Add to Home screen"** / **"Install"** চাপুন।
3. নোটিফিকেশন পারমিশন চাইবে, **"Allow"** দিয়ে দিন।
4. ব্যস! আপনার ফোনের হোম স্ক্রিনে অ্যাপের আইকন চলে আসবে।

## 📋 একাউন্ট লোড করার ফরম্যাট (Account Format)

**Load Accounts** বাটনে ক্লিক করে এক লাইনে একটি করে একাউন্ট পেস্ট করুন:
```text
email|password|refresh_token|client_id|recovery_email
```
*(প্রথম ৪টি ফিল্ড আবশ্যক, recovery_email অপশনাল)*

**উদাহরণ:**
```text
user1@hotmail.com|Pass123|0.AX4Aw...|1fec8e78-bce4-4aaf-ab1b-5451cc387264
user2@outlook.com|Secret99|0.AX4Aw...|1fec8e78-bce4-4aaf-ab1b-5451cc387264|rec@gmail.com
```
