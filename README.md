# 📱 MD Sojib - Live OTP Monitor & Auto-Copy App

**code.yamin.bd** API-এর সাথে সংযুক্ত রিয়েল-টাইম Hotmail ও Outlook ওটিপি মনিটরিং এবং ইনস্ট্যান্ট নোটিফিকেশন অ্যাপ।

---

## 🌟 প্রধান ফিচারসমূহ (Key Features)

1. **রিয়েল-টাইম লাইভ মনিটরিং (Real-Time Live Monitor)**:
   - একসাথে ১০টি বা ইচ্ছামতো Hotmail / Outlook একাউন্ট ব্যাকগ্রাউন্ডে চেক করতে পারে।
   - প্রতি ৩/৫/১০ সেকেন্ড পর পর নতুন OTP চেক করে।
   - একই পুরনো কোড বারবার নোটিফাই করে না, শুধুমাত্র নতুন OTP আসলেই এলার্ট দেয়।

2. **স্মার্টফোন এসএমএস নোটিফিকেশন ব্যানার (Heads-Up Banner)**:
   - ওটিপি আসার সাথে সাথে ফোনের স্ক্রিনের ঠিক উপর থেকে এসএমএসের মতো সুন্দর ব্যানার ভেসে ওঠে।
   - সার্ভিসের নাম (Google, WhatsApp, Instagram, Facebook, ইত্যাদি), ইমেইল এবং বড় করে জ্বলজ্বলে OTP কোড দেখায়।

3. **অটো-কপি (Instant Auto-Copy to Clipboard)**:
   - কোড আসার সাথে সাথে অটোমেটিক্যালি ক্লিপবোর্ডে কপি হয়ে যায় (`Copied to Clipboard!`)।
   - আপনাকে ম্যানুয়ালি সিলেক্ট বা কপি করতে হবে না।

4. **সাউন্ড ও ভাইব্রেশন এলার্ট (Chime & Vibration)**:
   - একদম ফোনের এসএমএস টোনের মতো মিষ্টি ডুয়াল-টোন রিংটোন বাজে (Zero-dependency Web Audio Synthesizer)।
   - মোবাইলে ভাইব্রেশন দেয়।

5. **স্ক্রিন ওয়েক লক (Screen Wake Lock)**:
   - ফোনের স্ক্রিন নিজে নিজে অফ বা স্লিপ হওয়া আটকে রাখে।
   - এটি অন থাকলে ডিসপ্লে সার্বক্ষণিক সজাগ থাকে, ফলে মোবাইল অপারেটিং সিস্টেম ব্যাকগ্রাউন্ড প্রসেস সাসপেন্ড করে না এবং ওটিপি আসার মুহূর্তের মধ্যে ক্যাচ হয়।

6. **ব্যাকগ্রাউন্ড কিপ-এলাইভ ও পিসি সার্ভার সিঙ্ক (Background Keep-Alive & Server SSE)**:
   - আপনি যখন অ্যাপ মিনিমাইজ করে ইনস্টাগ্রাম বা অন্য অ্যাপে কাজ করবেন, তখন সাইলেন্ট অডিও কিপ-এলাইভ ও পিসির নোড সার্ভার ব্যাকগ্রাউন্ডে মনিটর চালু রাখে।
   - ওটিপি আসার সাথে সাথে ফোনের স্ক্রিনে নেটিভ পুশ নোটিফিকেশন ভেসে ওঠে এবং শব্দ করে।

7. **অল-পারমিশন সেটআপ মোডাল (1st Launch Onboarding)**:
   - প্রথমবার অ্যাপে ঢোকার সাথে সাথেই এক ক্লিকে নোটিফিকেশন, সাউন্ড আনলক এবং ওয়েক লক পারমিশন চালুর সুন্দর মোডাল আসে।

8. **স্মার্ট টোকেন পার্সার (Smart Token Parsing)**:
   - `email|password|token|client_id` এর পাশাপাশি শুধু `email|password|token` অথবা `email|token` দিলেও চলবে।
   - `client_id` মিসিং থাকলে সিস্টেম স্বয়ংক্রিয়ভাবে মাইক্রোসফটের ইউনিভার্সাল ক্লায়েন্ট আইডি (`1fec8e78-bce4-4aaf-ab1b-5451cc387264`) বসিয়ে দেয়।
   - `|`, `----`, `:`, ট্যাব (`\t`) সব ধরনের ফরম্যাট এক ক্লিকে ডিটেক্ট করে।

## 🚀 কীভাবে চালাবেন (How to Run)

### ১. সার্ভার চালু করতে:
টার্মিনালে লিখুন:
```bash
npm start
```

### ২. কম্পিউটার থেকে দেখতে:
ব্রাউজারে যান:
```
http://localhost:3000
```

### ৩. মোবাইল ফোন থেকে অ্যাপ ব্যবহার করতে:
কম্পিউটার এবং আপনার মোবাইল ফোনটি একই ওয়াইফাই (Wi-Fi) বা হটস্পটে কানেক্ট করুন, এরপর:
- ফোনের ক্রোম (Chrome) ব্রাউজারে লিংকটি লিখুন:
  ```
  http://192.168.0.101:3000
  ```
- অথবা কম্পিউটারের স্ক্রিনে থাকা **"Phone Connect"** বাটনে চাপ দিলে একটি কিউআর কোড (QR Code) আসবে, ফোন দিয়ে স্ক্যান করলেই খুলে যাবে!

### ৪. ফোনে অ্যাপ হিসেবে ইনস্টল ও ব্যবহারের নিয়ম:
1. ফোনে লিংকটি ওপেন করুন।
2. অ্যাপে ঢোকার সাথে সাথে **"স্মার্ট পারমিশন সেটআপ"** মোডাল আসবে—**"সব পারমিশন চালু করুন"** বাটনে ট্যাপ করে নোটিফিকেশন Allow করে দিন।
3. Chrome ব্রাউজারের ৩ ডট মেনু (⋮) তে গিয়ে **"Add to Home screen"** / **"Install App"** চাপুন।
4. **Load Accounts** এ আপনার টোকেন পেস্ট করুন এবং **"START LIVE MONITORING"** চাপুন।
5. এবার ইনস্টাগ্রাম বা যেকোনো অ্যাপে কাজ করতে পারেন—ওটিপি আসা মাত্রই ফোনে এসএমএসের মতো নোটিফিকেশন পপআপ হবে এবং অটোমেটিক ক্লিপবোর্ডে কপি হয়ে যাবে!

## 📋 সাপোর্টেড একাউন্ট ফরম্যাট (Flexible Formats)

**Load Accounts** এ নিচের যেকোনো ফরম্যাট পেস্ট করতে পারেন:
```text
email|password|refresh_token|client_id
email|password|refresh_token
email|refresh_token
email----password----refresh_token
```
*(client_id অথবা password মিসিং থাকলে সিস্টেম নিজ থেকেই প্রয়োজনীয় ডিফল্ট ভ্যালু যুক্ত করে পাঠায়, ফলে কোনো API এরর হবে না)*
